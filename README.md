# SENTENCE GENERATOR
This is a java program running on the very fundamentals. It only uses `import java.util.Scanner` to take user input and a pre-defined set of instructions to create the random sentence. The script contains only 5 variables:
1. `const adjective1`: this is the first adjective in the sentence.
2. `const noun1`: this is the first and **ONLY** noun in the sentence.
3. `const adjective2`: this is the second adjective in the sentence.
4. `const verb1`: this is the first and **ONLY** verb in the sentence.
5. `const adjective3`: this is the last adjective in the sentence.

The code uses Scanners to ask the user all of the following types of words and then assigns them to suitable variables and after that it uses them to combine it with the preset text to finally generate the sentence.
